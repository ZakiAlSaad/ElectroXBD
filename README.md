## 📱 About

**ElectroX BD** is an Android application designed to provide a simple,
fast, and convenient shopping experience for electronics and robotics
enthusiasts in Bangladesh.

Whether you're a student, maker, hobbyist, engineer, or robotics enthusiast,
ElectroX BD helps you discover the components you need for your next project.

mobile shopping experience.

## 🚀 Getting Started

### Download

Download the latest version of the ElectroX BD Android application
from the release section.

### Installation

1. Download the APK.
2. Install the application on your Android device.
3. Open **ElectroX BD**.
4. Browse products and start shopping.

> **Note:** For the best experience, use the latest available version
> of the application.
